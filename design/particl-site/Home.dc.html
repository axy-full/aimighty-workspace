Stages

One project. One ledger.

Takes move draft → picked → approved, the Setup travels into every shot, and any stage can hand its work to Atomik as a priced plan.

One stage. The brief, the script and the development passes read and write the same document, so scene numbers stay bound to the boards, the shots and the takes that cite them. Development runs draft → critique → refinement on a planner you choose, quoted first.

A plan is a named sequence of priced steps you can edit before running. One plan can span Production, Marketing and the Viral Studio; run a whole stage, or step through it one action at a time.
