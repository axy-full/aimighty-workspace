# Mobile web — addendum to the Particl Suites handoff

Design reference: `Particl Mobile.dc.html` (+ `ios-frame.jsx` beside it; the phone bezel is presentation only). Same Graphite tokens as desktop; this is the **responsive web app below 768px**, not a native app. Everything the desktop does that makes sense on a phone is here; authoring-heavy surfaces (Rig wiring/lasso, Edit timeline, Astra viewport) stay desktop-only and the phone offers *run · approve · file* for them.

## Navigation
Bottom **tab bar** (82px incl. safe area, `rgba(0,0,0,.92)` + blur, hairline top): **Studio · Gen · Suites · Assets · More**. Active = `#0A84FF` icon + label (10.5px). Top bar: 54px status inset, 48px row (mark or `‹ Back`, running-jobs pill, `2,000 CR` mono, avatar), then a 44px **project bar** (`[DS] Dune Studies ▾` opens the Projects sheet · `16:9 · 24 fps`). Hidden on More.

Hit targets ≥44px everywhere; chips 36px; primary buttons 50px; inputs 44px with 16px text (no iOS zoom). Horizontal chip rows bleed to the screen edge (`margin:0 -16px; padding:0 16px; overflow-x:auto`). Sheets slide up (`om-up` 320ms), grab handle, ≤82% height, dim `rgba(0,0,0,.6)`.

## Behaviour parity with desktop
Same state model and endpoints (README › Backend contracts). Reference picking replaces drag-and-drop: every *Add* opens the Picker sheet pre-filtered for what the target accepts (`pickerFor` = gen | gjVideo | gjImage) and validates kind/role/count with a toast. Jobs stream into the header pill and Results ring; completion prepends a `NEW` asset and settles credits. Enhancer, `raw:` bypass, 1 cr, and the provider selector behave exactly as on desktop.

## Not on mobile (by design)
Rig node graph editing, Edit & Sound timeline scrubbing, Astra 3D viewport, Business Setup *creation* forms (view/select only), DTC image-ads composer (opens Gen with the `marketing_image` preset instead), Workspace › People/Engines editing (read-only rows). Each shows a one-line note pointing to desktop.
