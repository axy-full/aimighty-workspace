# Atomik model catalogue and reasoning

Since 22 October 2026 Atomik thinks with Claude only, at the workspace's Thinking setting: High, Medium or Low. Which model each setting runs is the deployment's env, one slot per setting (`ATOMIK_THINKING_{HIGH,MEDIUM,LOW}_MODEL`, effort `high` unless its `_EFFORT` says otherwise), described in docs/atomik-model-policy.md. It is never shown to a person. Grok has left Atomik; OpenAI stays only for the Treatment writer; the Gemini models stay in the verified text catalogue for the prompt enhancer. Runtime availability and token prices still come from the connected catalogue. Image generators, audio services, embeddings, Gemma and safeguard classifiers belong to other tools and are excluded from this planner.

The model picker and the effort picker are still on the screens until the Thinking control replaces them (its own PR). They are sent no list: the menus a member reads (GET `/api/atomik`, `/api/workbench/atomik`, `/api/workbench/development`) say only whether Atomik's thinking is connected (`configured`), so the pickers draw nothing, and what an older page sends is not a choice: the server ignores a sent model and effort, never refuses one, and runs the setting's. A chat saved on a model Atomik no longer thinks with reads as Auto, with nothing to say; a new request naming one is quoted and run on the setting's model. If a setting's slot is unset, its turns are refused; if its model is not being served, another slot's runs only if it is no dearer on every rate (input, output and both cache rates; the closest below first), priced as what runs; with none, the request is refused before anything is quoted or charged, and nothing falls back to another model or family. Quotes, chats, jobs and replies a member is sent carry no model or effort (docs/atomik-model-policy.md).

Reasoning effort is separate from response detail (Quick, Considered, Deep). The effort is the Thinking setting's, sent where the model's catalogue entry offers it; where the entry offers no effort control, none is sent and the model thinks at its own default. The model's capability metadata still determines what the compiler accepts; unsupported combinations are rejected before a claim or credit reservation.

The shared reasoning compiler builds the exact Gateway request controls. Native provider options are used where Gateway's generic effort translation would change the requested setting. Output reservations include the bounded reasoning allowance and the catalogue’s applicable context-tier token rates. Malformed or uncovered declared price tiers cannot become a free quote. Effort-controlled requests require an approved credit ceiling: every Studio Atomik job whose model offers the setting's effort, every run of Atomik's thinking for ideas, shot lists, a Treatment scene or the memory read, and every chat turn (owner, 23 Oct 2026: a turn without an approved ceiling is refused before anything is reserved or billed; for an API token or an MCP client before its request is claimed, for a browser session after the request is recorded and before any reservation). Their application safety ceilings default to $10 per request and $100 in Atomik work per production, so premium models fit. Explicitly configured lower ceilings remain effective; actual workspace balances, monthly limits and project budgets are still enforced by the atomic reservation. A request whose model offers no effort control keeps the former $0.25/request and $5/production guards. Credit pricing is unchanged. Requests exceeding any applicable cap are declined before inference. Selecting maximum effort does not promise an unlimited thinking duration or an unlimited token budget.

Workbench quotes include the total output ceiling; the model and effort that will run stay on the server. Paid requests persist these controls (the saved request records what runs) and the provider request before execution; identity conflicts are rejected. A request is fingerprinted on its body as sent, so pending requests from older deployments still find their job. Plans retain the effort that ran as provenance. Legacy writing tools also quote before submission and keep their older $1 request guard where no effort is sent. The worker permits up to 270 seconds within a 300-second function, and history does not expire a running job until six minutes. Ambiguous provider results retain their reservation and are not automatically submitted again.
