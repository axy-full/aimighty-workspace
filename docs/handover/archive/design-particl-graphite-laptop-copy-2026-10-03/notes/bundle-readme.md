# Particl: final design (Graphite)

`Particl Suites.dc.html` is the final design. Its shell and Studio's ten stages are finished. Gen, Business, Viral, Atomik, Crew and the phone are still to build; `PROMPT.md` is the prompt that builds them in Claude Design, one step at a time.

## What's here

| File | What it is |
| --- | --- |
| `Particl Suites.dc.html` | The final shell and Studio. Start here. |
| `Particl Gen.dc.html`, `Particl.dc.html`, `Particl Productions.dc.html`, `Particl Workspace.dc.html` | Earlier Graphite screens (15–16 September), the content source for the suites still to build |
| `Particl iPhone.dc.html` | The earlier phone design, to be rebuilt in the final shell |
| `Particl Canvas.dc.html` | Every earlier screen as live frames on one canvas |
| `support.js`, `ios-frame.jsx` | The runtime the files need beside them |
| `notes/` | The feature map, the suites spec and copy, and the Graphite handoff notes |
| `github.md` | The record of syncs with axy-full/aimighty-workspace |
| `PROMPT.md` | The prompt for Claude Design |

## Rules

- Keep the Graphite look as it is: black canvas, flat hairline panels, one blue accent. No Liquid Glass.
- Particl uses provider APIs only (28 September 2026), so nothing needs a Higgsfield sign-in.
- The files run in Claude Design or from a local web server. Opened by double-clicking, three of them (Productions, Workspace, Canvas) can't load the files they depend on.

Removed from the bundle Claude Design exported: the duplicate handoff folder, the Layered and Glass variants, and the v1 archive.
